.. _supportus:support_us:

Support Us
==========

There are many ways to support the project and we highly appreciate any kind of support!

.. _supportus:support_us-participate:

Participate
-----------

If you have questions or problems don't hesitate to get in touch using the mailing list or chat (see :ref:`support:resources_and_support-online_resources`).
Generally it is recommended to join those communication platforms as you will read news and you might be able to help each other.

.. _supportus:support_us-contribute:

Contribute
----------

No matter if you can translate, document or code: :ref:`techguide-contributing:contributing` is very welcome!

.. _supportus:support_us-spread_the_word:

Spread the word
---------------

As free software projects and communities we should support each other.
When you use GNU Health in your hospital, university or company: Please publish it on your blog or social media.
Similarly we acknowledge other free software projects if we use their software and try to get in touch.

.. _supportus:support_us-donate:

Donate
------

We have very limited resources and any donation can help a lot! Consider becoming a member of GNU Solidario (by default 120$/year) or giving a one time donation:

https://my.gnusolidario.org/donate/
