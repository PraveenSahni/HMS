Backup and Restore
==================

Traditionally backups and restore are handled using :ref:`techguide-administration-controlcenter:the_gnu_health_control_center`.

For more complex scenarios check the documentation of the Ansible deployment
which offers Roles for Barman & Restic to handle backup and restore:

https://docs.gnuhealth.org/ansible/backup.html

https://docs.gnuhealth.org/ansible/roles/barman.html

https://docs.gnuhealth.org/ansible/roles/restic.html
