The SYSINFO Command
===================

The SYSINFO command gathers information from both the client and server side of the GNU Health HIS node.
The information is shown in the GNU Health client **Activity log window**, press SHIFT + F12 to see it.
Some of the information retrieved by SYSINFO:

**Server Side**:

* Operating System
* Kernel version
* GNU Health server version
* Tryton kernel
* Python version
* GNU Health user

**Client side**:

* GTK Client version
* Operating System version
* Python version

If you run into issues with your system, please copy the output of SYSINFO and attach it to the message. It will facilitate sorting things out.
