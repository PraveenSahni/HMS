Release Process
===============

GNU Health HIS **stable** releases are those with even minor number, eg 1. **2** .3

.. _techguide-release:release_process-stages_of_the_release_process:

Stages of the Release Process
-----------------------------

For each version, some months before the actual release, GNU Health enters in feature freeze stage, and approximately two months before release, the GNU Health goes into code freeze. At this moment, no more code is accepted, except for bugfixes; the demo community server updated with the release candidate and the translator teams are notified.
