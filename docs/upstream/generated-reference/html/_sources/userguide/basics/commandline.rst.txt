Command Line
============

.. _userguide-basics-commandline:command_line-description:

Description
-----------

The native HIS client allows to use most of the functionality from the command line, without the need of the menu.
It's much faster and direct than the previous menu-based client. Of course, the menu is still available.

Most commands accept arguments, so the user can go directly to one specific instance of the resource. For example

.. thumbnail:: ../../images/gnuhealth_command_line.png
    :title: GNU Health command line highlighted in red executing the "PAT" command

PAT : List all the people registered on the system

PAT ESPGNU777ORG : Takes you directly to the patient with federation ID "ESPGNU777ORG"

.. _userguide-basics-commandline:command_line-accessing_the_command_line:

Accessing the command line
--------------------------
The command line can be accessed by clicking on the Command Line box (either at the top or bottom left of the client).

Clicking **SHIFT + Z** will put the focus on the Command Line Interface section.
