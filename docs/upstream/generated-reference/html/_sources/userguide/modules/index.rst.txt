Modules by functionality
========================

Until here we were only exploring the core module ``health``.

This chapter explains the functionalities of the other modules.

Note that we sometimes have multiple functionalities in one module and some functionalities involving multiple modules.

If you followed official installation methods you have all modules installed.
They can be activated inside the client: :ref:`techguide-development-modules:modules-activating_modules`.
