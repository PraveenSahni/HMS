Support Us

There are many ways to support the project and we highly appreciate any kind of support!

Participate

If you have questions or problems don’t hesitate to get in touch using the mailing list or chat (see Online resources). Generally it is recommended to join those communication platforms as you will read news and you might be able to help each other.

Contribute

No matter if you can translate, document or code: Contributing is very welcome!

Spread the word

As free software projects and communities we should support each other. When you use GNU Health in your hospital, university or company: Please publish it on your blog or social media. Similarly we acknowledge other free software projects if we use their software and try to get in touch.

Donate

We have very limited resources and any donation can help a lot! Consider becoming a member of GNU Solidario (by default 120$/year) or giving a one time donation:

https://my.gnusolidario.org/donate/
