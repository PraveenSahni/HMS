Backup and Restore

Traditionally backups and restore are handled using The GNU Health Control Center.

For more complex scenarios check the documentation of the Ansible deployment which offers Roles for Barman & Restic to handle backup and restore:

https://docs.gnuhealth.org/ansible/backup.html

https://docs.gnuhealth.org/ansible/roles/barman.html

https://docs.gnuhealth.org/ansible/roles/restic.html
