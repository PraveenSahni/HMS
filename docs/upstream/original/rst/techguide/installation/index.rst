Installation
============

GNU Health HIS node supports different types of installation methods:

* Traditional, generic "vanilla" installation (gnuhealth-control)
* Ansible (since 4.4)
* Packages from your operating system or distribution

.. important:: Do not mix installation methods. Choose only one.

Other installation methods are also collected.
