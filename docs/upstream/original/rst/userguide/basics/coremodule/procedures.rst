.. _userguide-basics-coremodule-procedures:procedures-about_prescriptions:

About Prescriptions
-------------------

Procedures are health interventions done on a patient. There are different contexts
where we can see this concept: Medical encounters, ambulatory care, surgeries. In
addition to these specific contexts, GNU Helth allows to create a procedure directly
related to a patient.


Procedures can accessed from *Health → Procedures* menu
Command: PROCS
